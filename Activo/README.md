 Activo!

Versión actual: 1.0 (Inicial - Esqueleto base)

Este es el repositorio inicial del proyecto Activo!, una aplicación diseñada para conectar a profesionales de servicios 
(mecánicos, limpieza, etc.) con clientes.

Estado del Proyecto
Actualmente, el proyecto se encuentra en su fase inicial. Es un lienzo en blanco para empezar a construir y diseñar.

Requisitos para compilar
- Android Studio (Rabbit 2).
- JDK 21 (el incluido por defecto en Android Studio).
- SDK mínimo: API 23.

Cómo ejecutar
1. Clona este repositorio.
2. Abre el proyecto en Android Studio.
3. Espera a que Gradle sincronice (descargará las dependencias básicas de Compose).
4. Presiona "Run" (Shift + F10) para ejecutar en el emulador.

Stack Tecnológico (Configuración inicial)
- Kotlin
- Jetpack Compose
- Material 3
- Gradle Kotlin DSL
- JVM Target: 21
